## 🎯 Objectifs du Projet

1. **Dashboard Maison 3D** : Vue isométrique interactive
2. **n8n Dashboard** : Orchestration workflow visuel
3. **Dashboard Obsidian** : Notes collaboratives + graphiques
4. **Synchronisation temps réel** : WebSocket entre dashboards

## 🎨 Principales Innovations

### 🔄 Boucles Automatiques (Loops)
- Surveillance population/ventes/performance
- Alertes automatiques
- Graphiques temps réel
- Actions corrigées

### 📈 Graphismes Interactifs
- Heatmaps, funnel, lignes dynamiques
- Click/hover pour drill-down
- Zoom/pan intuitif

### 💰 Optimisation Coûts
- Réduction 97% via token-optimizer
- Routeur modèles intelligent
- Budget alerts

### 🎓 Modes Dédiés
- **Mode Étudiant** : Guidelines, auto-validation, apprentissage progressif
- **Mode Codeur** : Productivité, qualité, déploiement automatisé

## 🛠️ Technologies

| Couche | Technologie |
|--------|-------------|
| Frontend | React + Tailwind CSS |
| Backend | Express.js + WebSocket |
| Base de données | SQLite + Redis |
| Orchestration | Custom agent scripts |
| Déploiement | Docker Compose |
| CI/CD | GitHub Actions |

## 📚 Comment Utiliser

### Pour les développeurs :
```bash
npm install
npm start  # Démarrage frontend + backend
```

### Pour les utilisateurs finaux :
1. Accédez à http://localhost:3000
2. Choisissez votre mode (Étudiant/Codeur)
3. Configurez vos boucles et graphiques
4. Suivez votre tableau de bord
